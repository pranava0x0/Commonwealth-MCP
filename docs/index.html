Real calls

↑ ↓

Fourteen real calls, one card each. Every card is built from the answer the tool actually returned, so this is what an AI agent would have seen.

Four of the calls go wrong on purpose. One asks about a name that matches two different governments. One searches and finds nothing. One asks about a place with no registered source. One fails outright. Most systems show you the same blank screen for all four, and they mean very different things.

Where a call went out to Fairfax County's live service, you can open the actual HTTP request that was sent. Where a call was answered from the local registry with no network request at all, the card says so.

Coverage

What this project can reach today: the tools an agent sees, the government services behind them, and the places they know about.

Tools

One MCP server exposes these. The code behind them is plain Python with no MCP dependency, so it can be tested without running a server. A profile controls how many tools an agent sees at once, because models pick the wrong tool more often as the list grows.

Government sources

Every question above is answered from one of these. Each is registered with a manifest that records what it publishes and what its terms allow. Ask about a place none of them covers and the answer says exactly that, rather than coming back empty.

Skills

A skill bundles several tool calls into one workflow. None are built yet. There is not enough coverage for one to be worth having, and a skill that only chains two tools together adds nothing a model cannot already do.

Quick start

↑

From the repo root. The tests run offline, replaying recorded government responses.

uv venv --python 3.12 .venv && uv pip install --python .venv/bin/python -e . --group dev
.venv/bin/commonwealth doctor --live
.venv/bin/commonwealth tools call geo.find_zoning \
  --args '{"jurisdiction": "Fairfax County", "pin": "0102 14  0231"}'
.venv/bin/commonwealth serve

That zoning answer comes from the county's GIS layer. It is a screening result, not a legal one. The adopted ordinance is what governs, and every answer says so.
